# 模块：Bing.Utils（核心）

## 1. 模块定位
- 目标：提供跨模块共享的基础工具能力与通用扩展。
- 非目标：不承载重量级第三方集成能力。
- 适用场景：基础字符串、对象、异常、参数校验等公共逻辑。
- 不适用场景：图像处理、外部 HTTP 特性扩展等专用能力。

## 2. 目录结构
    src/Bing.Utils/
    tests/Bing.Utils.Tests/

## 3. 对外 API
| API | 说明 | 参数 | 返回 | 异常 |
|---|---|---|---|---|
| `Guard.*`（示例） | 参数校验 | 输入对象 | - | 参数异常 |
| `ObjectExtensions.*`（示例） | 对象扩展 | 对象实例 | 处理结果 | 视实现而定 |

## 4. 核心类型
| 类型 | 职责 | 线程安全 | 备注 |
|---|---|---|---|
| `Guard`（示例） | 统一参数校验入口 | 是 | 需避免过度分配 |
| `*Extensions` | 通用扩展方法集合 | 取决于实现 | 尽量纯函数化 |

## 5. 依赖关系
- 直接依赖：`System.*`
- 可选依赖：无（建议）
- 禁止依赖：图像引擎/HTTP 客户端重量级库

## 6. 关键实现说明
### 6.1 算法/流程
- 统一 guard clause
- 高频路径优先 `TryXxx` 风格

### 6.2 边界与异常处理
- 输入空值、默认值、边界值处理
- 异常信息可定位参数名与调用场景

## 7. 性能与复杂度
- 时间复杂度：按方法标注
- 空间复杂度：按方法标注
- 大数据量表现：避免中间集合分配
- Benchmark 链接：`benchmarks/Bing.Utils.Benchmark`（如适用）

- 单测覆盖点：正常/边界/异常

# 模块：Bing.Utils.Drawing / Drawing.ImageSharp / Drawing.SkiaSharp

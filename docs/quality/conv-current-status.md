自然 GC 窗口内没有强制回收；窗口结束后才执行完整 GC。`List<int>` 的事件监听器未标记排空，因此该场景的事件暂停合计不作为完整值；表中暂停时间取运行时 `GC.GetTotalPauseDuration()`。固定类型和十秒窗口的存活结果没有显示持续增长，不能推断任意动态类型或生产 GC 模式的生命周期。旧框架基准为同运行配置的代表性采样，短窗口耗时有较大误差，仅将分配量作为稳定结论。

## 现存边界

- `OPEN_ACTIONABLE = 0`：原计划核心转换能力、自定义入口和本轮四项验收工作已完成。
- `ACCEPTED_LIMITATION`：最早历史 before 的完整源码身份无法恢复，不用当前候选哈希补填。
- `DEFERRED`：其他跨数值类型对和自定义列表元素需真实调用分布后再选择优化；不同生产 GC 模式下的吞吐需要对应环境测量。
- 原计划预期无需 `Unsafe`，当前内部可空值构造使用了项目已有的 `Unsafe.As`；相关类型精确检查、测试和四目标框架编译结果见历史验收记录。

本轮未改变包版本、提交或发布。

# Lambda 与反射二次修复记录

2026-10-29。状态：COMPLETED。二次审查中的 R1–R6 均为 CLOSED，独立复核确认 OPEN_ACTIONABLE=0。本记录描述本次修复；首次修复的记录与测量结果保留在原文件中。

## 本次修改

| 编号 | 问题 | 修复结果 |
| --- | --- | --- |
| R1 | 接口 `new` 隐藏属性可能错误选中基接口成员 | 路径解析从原始接口声明筛选，再按真实继承关系选择最派生的同名成员。无继承关系的同名声明保留歧义；协变可赋值性不再当作继承。公开及 IncludeNonPublic 路径结果一致。 |
| R2 | `x.Flags.Contains(text.Contains("a"))` 取到字符串参数而非计算结果 | 选定参数无关的查询值后按表达式实际求值，得到 bool；保留查询 Contains 提取独立值侧的既有约定。 |
| R3 | `!(A && B)` 条件计数退化为 1 | 穿透内置 bool 否定后统计逻辑叶节点，结果为 2；用户定义运算符及方法内部仍作为整体处理。 |
| R4 | 常量、闭包访问反复创建访问器与解释器 | 常见表达式节点直接检查自由参数；常量直接返回，安全的闭包/静态字段/引用属性链直接读取。仅在必要时进入解释器。预检查不执行用户代码，不缓存闭包或捕获值。 |
| R5 | 第二个动态属性立即创建字典，且缓存命中仍分配闭包 | 可回收动态实例先使用最多 8 个名称的小缓存，之后才创建字典，总容量仍为 1024；命中路径移除工厂闭包分配。CAS 使用同一快照检查和发布，避免并发重复插入。 |
| R6 | 重复取得强类型访问器仍反复验证并分配 | 已缓存且验证过的委托直接复用。泛型作用域只保存可回收性 bool；可回收签名/元数据仍旁路委托缓存。getter 与 setter 均采用该策略。 |

生产代码位于 `Lambdas.cs`、`Reflections.MemberPath.cs`、`Extensions.PropertyInfo.Typed.cs` 和 `DynamicBase.cs`。使用文档、缓存清单与回归探针已同步；本轮没有新增公开成员、依赖或目标框架。

## 性能确认

对比基线为二次审查时冻结的首次修复版本，复用已有确认数据。前后使用同一个无依赖探针二进制，各自启动进程加载指定程序集。本轮执行一次诊断和一次最终确认，不重复测量基线；最终确认在本任务的构建与测试完成后执行。
